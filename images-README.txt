Create a folder named "images" next to portfolio.html and put your screenshots in it with EXACTLY these names:

  images/rishtaelite.png
  images/thread-co.png
  images/ai-captioner.png

Recommended: 1280x800 PNG or JPG, under 500 KB each (resize/compress first).
If a file is missing, the card shows the project name on a styled background instead.
If you use .jpg, change the extension in the three <img src="images/..."> lines in portfolio.html.
