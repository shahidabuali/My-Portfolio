How I design.

The same four moves on every project, in this order.

I start on a blank frame

Every project begins as a Figma file, before any code exists. You see and approve the look first.

I design for real use

RishtaElite works in English and Urdu and in light and dark theme because those were design decisions, not extras added at the end.

I build what I drew

I write the code myself, so what you approve in the design is what ships.

I connect it and hand it over

Sign-in, database and real-time features go in with the build. You talk to me directly and get a live site with organized files.
